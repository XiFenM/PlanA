- **地点**：Santa Clara，以及 California、Texas、New York 的 Remote 选项
- **状态提示**：页面仍显示 Apply/existing vacancy，但官方所列“至少接受申请至 2026-07-20”已过，投递前必须重新核对
- **官方页面**：[NVIDIA Careers — JR2016392](https://nvidia.wd5.myworkdayjobs.com/en-US/NVIDIAExternalCareerSite/job/US-CA-Santa-Clara/Senior-Software-Engineer---AI-Inference_JR2016392?locationHierarchy1=2fcb99c455831013ea52fb338f2932d8)

### 主要要求

- 直接向 vLLM/SGLang 提交 feature、fix 和 optimization，并参与设计、review、benchmark 和测试。
- 优化 batching、scheduling、streaming、request lifecycle 和 KV paging/sharding。
- 从 Python orchestration 追到 C++/CUDA Kernel，建立 correctness 和 performance regression。
- 处理多 GPU 并行、通信、并发、可靠性和生产可维护性。

### 对准备的校准

这说明“上游 PR + benchmark/test + 当前框架主链”并不是 AMD 独有主题。对于高级开源推理框架岗位，公开可评审工件和回归体系是高频强信号或直接工作职责，但不同公司和职级的筛选强度并不相同。

- **地点**：上海
- **状态提示**：官方页面可访问；投递前重新复核是否仍接受申请
- **官方页面**：[NVIDIA Careers — JR2005687](https://nvidia.wd5.myworkdayjobs.com/en-US/NVIDIAExternalCareerSite/job/Senior-LLM-Train-Framework-Engineer_JR2005687-1)

### 主要要求

- 开发 Megatron Core，覆盖预训练、对齐、定制、评估和部署生命周期。

## 6. 不应过度扩张的内容

- 不需要同时深挖 CUDA、ROCm 和 Neuron 的所有工具链；本轮以 ROCm 迁移为主，CUDA/Neuron 只做方法对照。
- 不需要为了满足所有 JD 同时学习完整编译器、完整 Kernel 库和完整分布式训练框架。
- 不把厂商专有组件名当成能力本身；优先掌握接口契约、状态、数据路径、性能模型和验证方法。
- 不以岗位卡片替代官方页面；面试或投递前重新核对在招状态和完整任职条件。
