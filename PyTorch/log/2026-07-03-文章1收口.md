## 问答与要点

- [纠错] 场景：复述 torch.add 七步链第四步（连续两轮犯同一个错）。我说「requires_grad=true 所以 autograd key 最高」→ 正确：**Autograd key 在不在 keyset 高位决定走不走 autograd kernel（路由）；requires_grad 只是 kernel 内部"记录还是白过"的开关（记录）**。为什么：路由与记录是两层判断，keyset 由 tensor 属性算出，别把开关当路由。
- [纠错] 场景：回答 native_functions.yaml 语法（Q9）。我说「`!` 表示原地、`_` 表示修改输入」（把一层含义拆给了两个记号）→ 正确：**`_` 是纯命名习惯只给人看**（提示 in-place 变体，机器不读）；**`(a!)` 注解才是机器读的真值**（`a`=别名集标签，`!`=此参数被就地修改并喂 version counter +1）。为什么：两个记号各司一层——`_` 管人的预期，`(a!)` 管机器的真值。
- [要点] torch.add 从 Python 到 kernel 的完整七步链？——`THPVariable_add`（codegen 生成的 CPython 原生绑定，性能考虑不走 pybind11）→ `at::add` → dispatcher 算 keyset → `VariableType::add`（autograd kernel 记录）→ `at::redispatch::add`（排除 Autograd key）→ RegisterCPU 挂钩 → native kernel 内 dtype switch。（来源：文章1 §3.2）
- [要点] 同一算子在同一设备上为什么仍可能走不同链路？——至少四个分叉：requires_grad 开关（走不走记录层）、layout（strided/sparse 不同 kernel）、dtype（kernel 内 switch）、composite 分解（无专用 kernel 的算子拆成 aten 组合，链深都不同）。（来源：文章1 §读后回顾 Q13）
- [要点] 新增算子的标准流程动哪两张表、手填哪两个洞？——native_functions.yaml 声明接口，是**起点**：驱动 codegen 生成整条接线（Python 绑定 / C++ API / schema 注册 / 后端挂钩）；derivatives.yaml 声明反向。手写的只有 kernel 函数体和反向公式。我们 fork 整仓属 in-tree，享受 codegen；真 out-of-tree 插件才手写 `TORCH_LIBRARY_IMPL`。当初的错位：把 yaml 当"最后一步的注册动作"，且完全不知道 derivatives.yaml 存在。（来源：文章1 §4）
- [要点] yaml 条目不写 `dispatch:` 节会怎样？——不报错，视作 CompositeImplicitAutograd：函数体纯 aten 组合则前向反向全免费；混了裸指针/外部库调用则**前向照常、反向静默错误**——正是"只写前向、训练断梯度"现象的根。（来源：文章1 §4，面试Q&A）
- [要点] autograd 为什么对新后端"免费"？边界在哪？——autograd kernel 按算子注册（不按后端），反向公式是设备无关的 aten 组合，执行时 redispatch 回后端的**前向** kernel；前向注册全了反向白给。边界：fused 单体 kernel、外部库调用没有 aten 分解，必须自己提供 backward。（来源：文章1 §3）
- [要点] PyTorch 有没有现成的"自定义算子 vs 标准算子"自动对拍机制？——没有现成开关；我们环境变量触发的 CPU 对拍宏是自建的。`__torch_dispatch__` 是实现"影子执行"式通用对拍的现代标准挂点（待验证，欠债坑②）。（来源：文章1 §读后回顾 Q8）
- [要点] 对拍的参考实现为什么必须用 aten 组合、禁用裸 data_ptr？——校尺必须比工件直：裸指针带连续性假设，遇非连续输入静默读错数据，校尺自己先弯，对拍变成两个错误实现互相认证。（来源：文章1〔下游透镜·过往经验〕）
- [要点] 对拍宏的容差阈值为什么不是常数？——它是两条链硬件精度轮廓差异的建模，得逐算子、逐 dtype 校。我们两个方向都吃过误报：向量单元 fp32-only，bf16 升 fp32 算完再降回，自研端 bf16 反而**比 CPU 更准** → 假阳性；矩阵乘单元 bf16-only，fp32 矩阵乘天然**比 CPU 差**（硬件本底误差，多次 bf16 矩阵乘可拼高精度但拿时间换精度）→ 只能扩容差。（来源：文章1〔下游透镜·过往经验〕）
