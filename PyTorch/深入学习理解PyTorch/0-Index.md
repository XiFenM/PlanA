# 深入学习理解 PyTorch 学习笔记 第 0 节：引言

> 如果希望直接进入技术内容，或者已经熟悉 AI 框架，可以从第 1 节开始阅读。本节主要说明我为什么编写这个系列，以及后续文章如何组织。

截至 2026 年，大模型训练和推理已经成为 AI Infra 的重要工作内容。对从业者来说，理解机器学习框架的底层机制是一项实用能力。PyTorch 是目前的主流框架之一，也是值得系统学习的对象。下图展示了截至 2024 年 9 月，Papers with Code 收录论文中各深度学习框架的使用占比。

![Papers with Code 收录论文中的深度学习框架使用占比](image.png)

> 图表来自 Papers with Code 的 [Frameworks 趋势页面](https://paperswithcode.com/trends)，截图数据截至 2024 年 9 月。该地址目前会重定向到 Hugging Face 的论文趋势页；59% 这一统计也可在 Horace He 2025 年的[相关文章](https://www.thonking.ai/p/why-pytorch-is-an-amazing-place-to)中交叉确认。

图中 PyTorch 的占比为 59%。Megatron、vLLM 和 SGLang 等训练或推理框架也以 PyTorch 为基础。Papers with Code 后来不再公布这组统计，因此我无法从同一数据源确认当前的具体比例。

PyTorch 使用广泛，但日常使用并不要求我们完整理解它的内部机制。我自己也是在工作中遇到问题时，再针对具体模块阅读源码，对许多部分仍缺少系统认识。

因此，我准备按照一条完整的路线学习 PyTorch，并记录学习过程。这些记录一方面方便我以后回顾，另一方面也可以为想了解 AI 底层加速的读者提供一份参考。我刚进入 AI Infra 领域时，也曾不清楚应该从哪里开始。

这个系列会以实际学习者的视角展开，而不是把我包装成已经掌握全部答案的老师。我会保留学习前的判断、中途的误解和最后的修正，让读者看到这条学习路径实际是如何展开的。后续文章大致采用以下结构：

```Markdown
## 资料来源
文章是我对资料的理解、整理和加工，其中也包含个人实践与思考，不能保证完全准确。文章开头会列出学习资料，方便读者查看原始内容并交叉验证。

## 先猜再学
在正式学习之前，我会根据标题、资料标签和已有经验，提出希望回答的问题，并记录当时的直觉。这样可以在学习过程中主动寻找答案。

### 当前知识背景
我会说明自己对当前主题已经掌握的知识和实践经验。

文章默认读者具备大学一年级左右的基础，了解微积分和 C/C++ 编程的基本概念，但不要求掌握特定技巧。如果某一部分仍然跳跃，读者可以结合这份背景说明，补充相关的基础知识。

### 期望回答的问题
这部分通常包含三类问题：

- 从工程实践出发，我希望了解的内容；
- 过往工作中遇到的问题；
- 初学者可能需要补充的预备知识。

### 我的直觉
我会先记录自己对上述问题的初步判断。如果问题来自实际工作，也会说明当时采用的处理方式。这些判断和方法未必完整，将在学习后重新检查。

## 学习过程
这是每篇文章的主要部分。我会按主题重新组织资料，不一定遵循原资料的顺序。内容可能包含：

1. 原文转述；
2. 我的思考与理解，包括质疑、误解和对难点的处理；
3. 辅助理解的图示；
4. 源码或文档锚点；
5. 与直觉不一致的结论；
6. 尚未理解的问题。

原文转述和个人理解会贯穿各个主题，其他内容则根据需要补充。为了保持阅读的连贯性，我会在段落中结合转述、思考、图示和源码锚点，不再将它们拆成固定的小节。

## 读后回顾
完成学习后，我会对比学习前的直觉和资料给出的答案，将原有判断分成三类：

1. 直觉成立；
2. 对了一半；
3. 明显错位。

## 实践
完成资料学习后，我会尽量设计小型实验来验证理解。实验通常需要额外时间，因此不一定会随文章首次发布，后续可能再补充。

## 实际工作与面试
这部分会将学习内容与实际工作和面试问题联系起来。

### 过往经验
如果主题与我的过往工作相关，我会补充当时的处理方式。这些经验不一定适用于其他环境，仅作参考。

### 面试问题 Q&A
我会根据当前主题整理几个可能出现在面试中的问题，并给出当时的理解。答案可能存在疏漏，欢迎读者指正。

## 思维导图总结
我会使用思维导图整理文章的主要关系，便于后续回顾。

## 后续预告
这部分主要记录：

- 尚未解决的问题；
- 由当前内容延伸出的想法；
- 按照学习计划安排的下一篇文章。
```

这套结构是我与 AI 对话后整理出来的。固定结构可以降低我初次编写长篇博客的难度，也方便读者定位感兴趣的内容。它也可能让不同文章显得过于相似，后续我会根据实际写作效果调整。

本系列是对学习资料的整理和个人理解，不能代替对源码、机制和理论原文的直接阅读。我会尽量补足理解所需的背景，但仍建议读者将文章与原始资料对照阅读。
