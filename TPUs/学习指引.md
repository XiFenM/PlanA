# TPUs 学习指引（Track B 精简版 / 30-40h 可完成）

## 0. 入场点

- **定位**：这是 **Track B**，不在 20 周主线里——offer 后 / 有余力时看。30-40h 可完成一轮。
- **你的本职是非 NV、非 TPU 自研芯片，为什么还学 TPU？** 四个理由：
    1. **唯一大规模生产的非 NV 成功案例**：TPU 是目前唯一能和 H100/B200 在大规模训练 / 推理上正面竞争的非 NV AI 芯片。**它的栈设计（硬件抽象、kernel 语言、分布式原语、编译栈）是你家芯片最直接的参考样板**
    2. **分布式并行的第一原理**：Google 的《Jax Scaling Book》是业界**唯一**从第一原理讲"怎么为 XPU 设计并行策略"的教材，模型无关、硬件无关——这些方法论无损迁移到你家芯片
    3. **Pallas + Mosaic 作为 DSL 参考**：Pallas 是 TPU 侧的 "Triton 对等物"，Python DSL 写 XPU kernel。你家芯片如果将来要做类似 DSL，Pallas 设计哲学是最好起点
    4. **MaxText 有 ROCm fork 存在**——这是业界验证的"非 NV 非 TPU 芯片适配 JAX/MaxText 是真实路径"的证据。**这对你家芯片有直接战术意义**
- **终点（30-40h 后应该能做到）**：
    1. 能白板讲任意 (模型规模, 硬件规模, 互联带宽) 下的并行策略推导（跨 TPU/GPU 通用）
    2. 能讲清 TPU 代际演进（v5e / v5p / Trillium / Ironwood）的架构选择
    3. 能 10 分钟对比 **Pallas / Triton / 你家芯片 DSL** 的设计哲学
    4. 能在讨论"下一代 AI 加速器"时对 Cerebras / SambaNova / Tenstorrent 各自的路线有判断
    5. 能写一份"我家芯片 vs TPU"内部对标文档（阶段 3 产出）
- **不求达到**：能写 TPU kernel、贡献 JAX / XLA 代码、独立运维 TPU pod

#### A.2 TPU 8 引入的新架构范式（⭐ 对非 NV 芯片工程师战术意义最大）

**CAE (Collectives Acceleration Engine) —— 片上集合通信加速**
- 8i 新增的片上单元，**片上 collective 操作延迟降低 5×**
- 对比：NV 那边 NCCL 是 software + proxy thread + IB 网络的组合，TPU 8i 直接硬件化
- **战术意义**：你家推理芯片如果有类似需求，可参考这条硬件化路径；面试讲"MoE all-to-all 的硬件化可能"时是极好素材

**片上 KV Cache（8i）**
- 推理芯片专门设计：在片上显式管理 KV cache，"breaks memory wall"
- **战术意义**：和 [推理框架/学习指引.md](../推理框架/学习指引.md) §B PagedAttention 路线对比——一个是软件分页解决碎片，一个是硬件显式管理

**Boardfly 拓扑（8i 侧）**
- 36×8×4 = 1,152 芯片，**7 跳直径** vs v5p/Ironwood 3D Torus 的 **16 跳**
- 高 radix、低延迟，面向推理工作负载的通信模式
- **战术意义**：推理 pod 互联拓扑设计新范式；和训练侧 3D Torus 分道扬镳

**原生 FP4 MXU**
- 8t 12.6 PFLOPs / 8i 10.1 PFLOPs 都是 FP4 原生
- **FP4 MXU 吞吐相比 FP8 翻倍**——这是"低精度训练"从研究走向硬件的标志
- 结合 [模型理论/学习指引.md](../模型理论/学习指引.md) §F 资料 30b NVFP4 预训练，TPU 8 是 NV 之外第二个硬件级支持 FP4 的厂商

**Virgo fabric**
- 数据中心级网络，**47 Pb/s、4× DCN**，可扩展到 **>1M chips**
- 对比数据：**Virgo 支持 134,000 TPU 8t per DC** vs NV Vera Rubin NVL72 最多 80,000 GPU per DC
- **战术意义**：面试讲"芯片规模扩展的瓶颈在网络而不是芯片"时直接引用这组数据

**训练/推理双芯片拆分**
- 8t 训练芯片面向 batch 大、通信量大的训练负载
- 8i 推理芯片面向延迟敏感、KV 管理重的推理负载
- **战术意义**：**"一颗芯片打天下"时代结束**。你家芯片未来路线图是否也要拆训练/推理？这是面试可讨论的战略话题
