**032 · 助手 / 正式回答** · `2026-11-19T08:29:52.620Z` · `msg-a565d9ca4e733fcd9a77`

是的，\(R(\alpha)\) 左乘一个**二维列向量**，就让它在平面里旋转 \(\alpha\)。你对维度的检查是对的：\(2\times2\) 的矩阵直接乘 \(128\times1\) 的完整查询向量，尺寸确实对不上。

我们把记号分开。用 \(q_m\) 表示位置 \(m\) 上一个注意力头的**完整查询向量**。在这版 Qwen 里，从 0 开始编号，第一对取第 0 和第 64 个分量。把它俩单独拿出来，就得到一个 \(2\times1\) 的列向量：

\[
u=\begin{pmatrix}q_m[0]\\q_m[64]\end{pmatrix}.
\]

现在就可以算 \(R(\alpha)u\) 了。比如这两个分量原本是 \(1\) 和 \(0\)，让它们逆时针转 \(90^\circ\)：

\[
\begin{pmatrix}0&-1\\1&0\end{pmatrix}
\begin{pmatrix}1\\0\end{pmatrix}
=
\begin{pmatrix}0\\1\end{pmatrix}.
\]

把结果放回原位置，输出向量的第 0 个分量变成 \(0\)，第 64 个变成 \(1\)。接下来，\((1,65)\)、\((2,66)\) 一直到 \((63,127)\)，每一对都按各自对应的角度做同样的计算。

所以，**旋转整个头，就是让它的 64 对分量各自在自己的二维平面里旋转**。转完仍是 128 维。\(k_n\) 的算法相同，角度由键所在的位置 \(n\) 和该对分量的频率决定。

**035 · 助手 / 正式回答** · `2026-11-19T08:34:24.095Z` · `msg-99abf82e291dd860cd30`

可以让第 0 和第 1 个分量配对。**Qwen 取第 0 和第 64 个，是因为它把一个头的 128 个分量分成了两半。** 前 64 个分量充当 64 个旋转平面各自的第一个坐标，后 64 个充当各自的第二个坐标。于是两半对齐后，第一对自然是 `(0, 64)`，第二对是 `(1, 65)`。源码就是把向量从中间切开，再对两半做逐元素乘加。[vLLM 的两种配对实现](https://github.com/vllm-project/vllm/blob/4ba787ec9959e566d3b587a796dff07673324da5/vllm/model_executor/layers/rotary_embedding/common.py#L154-L169)

把例子缩到 4 维。假设我们希望一起旋转的两对分量是 `(a, b)` 和 `(c, d)`。

```text
分半排列   [a, c, b, d]    取下标 (0, 2) 和 (1, 3)
相邻排列   [a, b, c, d]    取下标 (0, 1) 和 (2, 3)
```

这两行旋转的都是 `(a, b)` 和 `(c, d)`。只要 Q 和 K 都按对应方式排列，每一对仍用原来的频率和位置坐标，旋转后的点积就相同。

**区别出在保留同一串数，却只换配对规则。** 假如训练好的投影仍输出 `[a, c, b, d]`，改用相邻配对后，第一对就成了 `(a, c)`。转过角度 \(\alpha\) 时，第一项原本是 \(a\cos\alpha-b\sin\alpha\)，现在成了 \(a\cos\alpha-c\sin\alpha\)。混入的是另一个分量，不同位置之间的注意力分数一般也会变。

所以，已有的 Qwen 权重要等价切换到相邻配法，需要在旋转前把每个头的 Q、K 通道同步重排，让原来一起旋转的两个分量仍然成对。
