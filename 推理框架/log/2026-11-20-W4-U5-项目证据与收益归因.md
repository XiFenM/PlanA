## 学习过程

<a id="w4-u5-p01"></a>

- [要点] 新算子版本只切换布局，能把所得差值报成当时个人节省的时间吗？我主动拆出自己做的 OOM 定位、模型侧调用和初始化权重布局，以及算子同事的专用实现。对照能支持新版本、同一组图片上的布局差异。原项目端到端记录对应双方改动共同落地后的结果。（消息 `msg-3d117b96d0b77ff94f2e`、`msg-6981f9594134e8f485b5`、`msg-53d192a00826c0da8286`）

<a id="w4-u5-p02"></a>

- [要点] 面试官问 Conv3D “解决了什么”，先选哪类请求？视频请求对应 OOM 现象，32B 的十个图片用例对应平均 TTFT 与图片模型级 token 对照。学习者后来补上一句“只指视频，图片做过”，避免把“视频回归缺失”误记成整个项目未做模型回归。（消息 `msg-3d117b96d0b77ff94f2e`、`msg-6981f9594134e8f485b5`、`msg-53d192a00826c0da8286`、`msg-766b4dcd13030f7f90c5`、`msg-706eb180f4a73f042633`、`msg-f832e1c1fa0ffa5dc2da`）

<a id="w4-u5-p03"></a>

- [要点] ECG 把 30–40 秒降到 20 秒以内的数字能搬到 vLLM 吗？我指出它来自原 Transformers 服务，终点是完整输出。题设中的 vLLM 布局对照只提供逐元素相同的 MatMul 输出和较短的平均 TTFT。若要报告 vLLM 完整请求，应固定输入、并发与生成设置，从各自客户端发送时刻量到完整输出。（消息 `msg-53d192a00826c0da8286`、`msg-98c7310d1afd111880cf`、`msg-b5be1236c12edc977816`）

<a id="w4-u5-p04"></a>

- [高价值问题] 回听异步异常时，哪里已经听清，哪个数还需要核实？我听出了 Host padding 尚未完成、下游消费者已经走到等待点的时序。现场报的次数、分母和对应阶段仍听不清，后来项目卡上的多轮回归次数不能拿来填原声的空缺。（消息 `msg-6aa11ef0a5a5a75550b3`、`msg-369f93435ed19e1a3fb2`）

<a id="w4-u5-p05"></a>

- [转折] 我补充了修复的两端：CPU 开始 padding 前就给源、中间和目标张量登记未完成标记，异步拷贝真正结束后才标记完成，下游 kernel 启动前等待它。这样即使 H2D 尚未提交到流上，消费者也知道准备工作还在进行。项目卡明确记有中间张量，三个对象都在 padding 前登记来自本次回忆。（消息 `msg-6aa11ef0a5a5a75550b3`、`msg-369f93435ed19e1a3fb2`、`msg-144e734b3310a461d0bd`、`msg-ec4b2968935b20fa6132`）

<a id="w4-u5-p06"></a>

- [纠错] 我先把两个项目合在一起说“都做过模型回归”。复核后要分开：ECG 在同芯片上比较预排布前后，核对所测 logits 和 token。32B 图片做过仅替换 CPU Conv3D 的整模 token 对照。视频有算子检查与跑通证据。对同一视频和提示词仅切换 CPU Conv3D 比生成序列，是我提出的补测。（消息 `msg-84b987455a8b7de5861c`、`msg-766b4dcd13030f7f90c5`、`msg-c21b7f77648138436d0f`、`msg-706eb180f4a73f042633`、`msg-f832e1c1fa0ffa5dc2da`）

<a id="w4-u5-p07"></a>

- [要点] 视频生成在第 8 个 token 分叉时，怎样定位是不是 Conv3D 造成的？我选择只替换这一处算子的参照，减少整模 CUDA 其他算子带来的差异。这个用例产生同一串贪心 token，仍可能对应不同的数值。判断单算子是否合格还得比较同输入、同权重的输出张量和容差。（消息 `msg-84b987455a8b7de5861c`、`msg-c21b7f77648138436d0f`、`msg-f832e1c1fa0ffa5dc2da`）

<a id="w4-u5-p08"></a>

- [高价值问题] 三个项目怎样回答第一轮介绍和后续代码追问？我希望每案都有能直接讲的版本。最终按“现象、定位、个人改动、验证边界”串起开场，再按项目回到[Conv3D、ECG 与异步 H2D 的追问和白板示例](../../课程网页/八周计划/plana-jd-w4-case-evidence-audit.html#interview)。（消息 `msg-f354eaed187c9934ba1a`、`msg-61348114e0998f99807c`）
