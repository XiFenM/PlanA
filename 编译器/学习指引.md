# 编译器学习指引（Track B 精简版 / 50h 可完成）

## 0. 入场点

- **定位**：这是 **Track B**，不在 20 周主线里——offer 后 / 有余力时看。**50h 可完成一轮入门 + 选 2 个栈深入 + 前沿对标**，不求覆盖全部。
- **为什么学 + 对你本职的意义**：你在**非 NV 自研芯片**上做推理/训练栈适配，本职工作邻域就包含一个编译器栈（你司芯片肯定有某种自研 DSL 或 MLIR-based 栈）。学这一节的**目标价值**是：
    1. **系统思维**：能讲清 `Python → Dynamo → ATen IR → Inductor IR → Triton/C++ → PTX/ASIC` 的层次化分解哲学
    2. **对标能力**：面试被问"你家自研编译器 vs XLA vs Triton 有什么差别"时能讲清设计空间
    3. **贡献能力**：offer 后如果要给自家栈写 MLIR pass 或新增 dialect，有足够前置知识入门
    4. **观察业界趋势**：**NVIDIA 自己 2025-12 开源了 CUDA Tile IR（MLIR-based）**——这是强信号，所有芯片的编译栈都在朝 MLIR 汇聚。你家芯片将来大概率也会走这条路。
- **终点（50h 后应该能做到）**：
    1. 能独立读 MLIR Toy Tutorial 7 章并写一个自己的 dialect + 一个 pass
    2. 能读 Triton 源码追一条 lowering 路径（Python → TTIR → TTGIR → LLVM）
    3. 能讲清 `torch.compile` 的三层（Dynamo / AOTAutograd / Inductor）各自解决什么问题，以及为什么是这么划分的
    4. 能用 10 分钟对比 **Triton / Pallas / XLA / IREE / CUDA Tile IR** 这 5 种主流编译栈的设计哲学和适配成本
    5. 能参与讨论"你家自研芯片接主流框架栈最轻量的路径"并提出具体路线图
- **不求达到**：能写一个 production-grade backend、能给 LLVM/MLIR 提有分量的 PR、能发表编译器论文

## 3. 实战任务（offer 后有余力做）

### 任务 1 — MLIR 自定义 dialect + 一个 Pass（阶段 1 末，8h）

- **要求**：基于 j2kun tutorial 的基础，自己定义一个小 dialect（比如 "mychip" dialect 模拟你家芯片的特殊 op），写 1 个 Pass 完成一个具体优化（比如算子融合或特殊 layout 转换）
- **产出**：`编译器/my_first_mlir_pass/`（可编译能跑）
- **为什么做**：一次做穿 "dialect 定义 → ODS 写 op → Pass 实现 → pipeline 接入" 的完整流程

### 任务 2 — 给 Triton 追一条 lowering 路径（阶段 2 末，4h）

- **要求**：挑一个最简单的 Triton kernel（比如 `01-vector-add`），开 `TRITON_INTERPRET=0 TRITON_DEBUG_IR=1` 环境变量或者用 Triton API dump 出各阶段 IR
    - 收集：Python AST → TTIR → TTGIR → LLVM IR → PTX
    - 挑一两个关键 lowering 步骤，能解释"为什么这一步要这么降"
- **产出**：`编译器/triton_lowering_trace.md`（带各阶段 IR 样本 + 注释）

### 任务 3 — 三栈对比博客（阶段 3 末，选做，4h）

- **要求**：写一篇 2000 字博客：**"Triton / PyTorch Inductor / CUDA Tile IR 三栈对比"**
    - 每栈：入口（用户写什么）、IR 层次、lowering 关键决策、适配新硬件的成本
    - 结尾：你家自研芯片接主流栈最轻量的路径猜想
- **产出**：`编译器/blog_three_stacks.md`
- **为什么做**：面试被问"你对编译器栈怎么看"时直接把博客大纲背出来就能讲 20 分钟
