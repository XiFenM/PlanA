- [词块] turn an entire Git repository into an interactive code knowledge graph = 把整个 Git 仓库转换成可交互的代码知识图谱

  - 为什么：turn A into B 自然表达“把 A 转换成 B”；interactive code knowledge graph 比笼统的 code map 更精确
- [词块] get up to speed on an unfamiliar codebase = 快速熟悉一个陌生代码库
  - 场景：说明希望借助图谱快速学习 vLLM 等 GitHub 开源项目
