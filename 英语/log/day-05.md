- [要点] 怎样表达“把整个 Git 仓库转换成可交互的代码知识图谱”？——`turn an entire Git repository into an interactive code knowledge graph`。
  - 场景：描述希望用 Graphify、CodeGraph 等工具可视化包含大量文件的源码仓库
  - 为什么：`turn A into B` 自然表达“把 A 转换成 B”；`interactive code knowledge graph` 比笼统的 `code map` 更精确。
- [要点] 怎样表达“快速熟悉一个陌生代码库”？——`get up to speed on an unfamiliar codebase`。
  - 场景：说明希望借助图谱快速学习 vLLM 等 GitHub 开源项目
  - 为什么：`get up to speed on` 是工程沟通中表示“快速补齐背景并达到可工作理解程度”的常用表达。
