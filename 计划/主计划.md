# 主计划

## 0. 目标与预算

- **目标**：5 个月内进入面试窗口，主攻推理框架优化岗（vLLM / SGLang / TensorRT-LLM 团队、自研芯片推理栈、大厂推理 infra），次主攻训练框架/分布式（Megatron Core、FSDP、HuggingFace Accelerate），再次算子开发（Triton、CUDA kernel）。
- **时间预算**：20 有效周 × 32.5h/周 ≈ **650 小时**。工作日每天 4.5h，周末单日 10h。
- **硬件**：工作日用公司 H100，周末用家里 4070 Ti。凡是需要 NVLink / 多卡 / 大显存的实验放工作日。
- **两条轨道**：
    - **Track A 面试冲刺（本文件 §2~§6）**：20 周主线，聚焦核心 + 其他够用。
    - **Track B 增强扩展（§7）**：offer 后 / 有余力时继续，覆盖编译器、TPU、RL、Rust 服务层等。
- **两条全程并行子轨道（不占主线周次，每天独立时间块）**：
    - **Leetcode**：每日 ≈45 min，已含在 32.5h 预算内（见 §4）。
    - **英语（听力/口语）**：每日额外 60–75 min，**不含在 32.5h 学习预算里**（属于"工作之外的日常习惯块"），22 周轴，比冲刺多跑 2 周到 W22。计划见 [英语/学习指引.md](../英语/学习指引.md)，进度见 [英语/进度.md](../英语/进度.md)。

## 1. 每周节奏模板（32.5h / 周）

| 时段 | 时长 | 内容 |
| --- | --- | --- |
| 工作日 × 5（4.5h/天）| **22.5h** | 当周主线板块（读资料 + 跑 demo + 读源码）|
| 周末单日（10h）| **10h** | 周末深度实战 + 本周复盘笔记 + 1 篇精读论文 |
| 每日首 30–45min | ≈4h/周（已含在上面）| Leetcode（雷打不动）|

**每日典型工作日（4.5h）**：
1. 0:00–0:45 — Leetcode 2 题（1 新 + 1 复习）
2. 0:45–2:30 — 主线资料精读（~1.5h）
3. 2:30–4:30 — 主线实战/源码/跑实验（~2h）

**每周末（10h）**：
- 上午 4h：本周最难一篇论文精读 + 复现 demo
- 下午 3h：周报笔记（写一篇面向自己的"复述"博客草稿，放到对应板块目录下）
- 晚上 3h：Leetcode 周末 batch（6–8 题，按主题专攻）+ 1 套模拟面试题（第 17 周起）

**英语并行块（每天 60–75 min，独立于上面 32.5h）**：
- 工作日：多邻国 10 min + 口语课 2 集（含课后录音）+ AI Infra 听力 3 遍法 15 min + Anki 复盘 5 min（午休/晚饭后再加美剧 1 集，可选）。
- 周日：英语周末加量 60 min（mini-talk 录音 + 回听口语课录音 + 播客深度 shadowing + 整理 Anki + 填 [英语/进度.md](../英语/进度.md) 周打卡）。
- 完整每日时间块拆解、4 套练习 SOP、分阶段升级见 [英语/学习指引.md](../英语/学习指引.md)。**铁律**：英语是"日常习惯块"，断链才是最大失败模式——错过一天可以，不许追加补量。

## 4. Leetcode 子轨道

> 20 周全程并行，不单独占周；目标进入面试前累计 **250 题左右**。

- **工具**：NeetCode 150 为主线，LeetCode 热门 100 补充，重点公司题库（Nvidia / Meta / Anthropic / 字节 / 阿里）最后 4 周刷。
- **节奏**：每工作日 2 题（1 新 1 复习）≈ 45 min；周末 batch 6–8 题 = 1.5h。
- **分布**：
    - W1–W4：数组 / 双指针 / 滑窗 / 哈希 / 二分 ≈ 60 题
    - W5–W8：链表 / 栈 / 队列 / 堆 / 单调栈 ≈ 50 题
    - W9–W12：树 / 图 / DFS / BFS / 并查集 ≈ 55 题
    - W13–W16：DP（线性 / 区间 / 背包 / 状态压缩）≈ 50 题
    - W17–W20：贪心 + 分治 + 高频 + 手撕多线程（CUDA top-k、线程安全队列）≈ 35 题
- **系统技术面专题**：按 [common_problems.md](../面试准备/common_problems.md) 里"CUDA 编写 top k 堆排序"、"CUDA 多线程中线程安全的生产者消费者队列"、"线段树"等做专门训练，最后 2 周每周 3 题。

详见 [Leetcode/学习指引.md](../Leetcode/学习指引.md)。

## 5. 检查点（Self-Check）

每 4 周做一次"假面试"自查，每次挑 2 个问题白板讲 10 分钟：

| 检查点 | 周 | 必须能白板讲 |
| --- | --- | --- |
| CP1 | W4 末 | Tensor stride & contiguous / `torch.add` 的完整调度链路 / PagedAttention block table |
| CP2 | W8 末 | vLLM V1 scheduler / Continuous batching vs static batching / RadixAttention LRU |
| CP3 | W12 末 | FSDP 三阶段通信时序 / TP 在 MLP 和 Attention 的切法 / 1F1B 气泡公式 |
| CP4 | W16 末 | Triton block programming vs SIMT / FlashAttention-2 online softmax 数学 / MLA 低秩压缩 |
| CP5 | W20 末 | 3 个项目故事（STAR）/ 5 道系统设计题 / 250 题 Leetcode |

不通过就**当周延长 2 天**补课，不允许硬推进度——记住这是以 Demo/能讲出来为准，不是以"读完了"为准。

## 7. Track B 增强扩展（offer 后 / 有余力）

不排入 20 周主线，但优先级明确，跳槽成功后按此顺序继续：

1. **编译器深度（MLIR）**：Toy Tutorial → Triton dialect → 为虚拟后端写 Pass。参考 [编译器/学习指引.md](../编译器/学习指引.md)。
2. **CUTLASS + CuTe**：布局代数、Hopper WGMMA、TMA。参考 [并行计算编程/学习指引.md](../并行计算编程/学习指引.md) §Track B。
3. **TPU / Jax Scaling Book**：[Jax scaling book](https://jax-ml.github.io/scaling-book/) 全册精读。参考 [TPUs/学习指引.md](../TPUs/学习指引.md)。
4. **Ray 分布式编排**：Actor / Task / Ray Train / Ray Serve。
5. **RL post-training（GRPO / DPO）**：DeepSeekMath + DeepSeek-R1 paper。
6. **Rust 服务层**：Pingora / tokio / Rust-based inference router（`mistral.rs` 等）。
7. **C++ 深入**：`libtorch`、`aten` 贡献一个 PR。

> Track B 每个主题独立成小计划，不要和 Track A 混着跑，否则都做不深。
