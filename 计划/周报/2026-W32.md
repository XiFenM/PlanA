> **DFlash → DSpark 去重**：DFlash 已在 W26 收录，不重复新增主条；补齐 [DFlash 论文](https://arxiv.org/abs/2602.06036)、[官方代码](https://github.com/z-lab/dflash) 与 [vLLM 文档](https://docs.vllm.ai/projects/speculators/en/latest/user_guide/algorithms/dflash/)。DSpark 以 DFlash 的 parallel backbone 为基础，增加块内顺序建模和置信度驱动的可变验证长度；它是后续独立系统，不是“DFlash V2”。

> **Kimi K3 的 Context Parallel 口径**：① K3 技术报告的 **KCP** 是 `KDA Context Parallelism`；② vLLM 的 **DCP** 是 `Decode Context Parallelism`，通过序列维分片减少 decode KV 重复；③ **PCP** 是 `Prefill Context Parallelism`，分片长输入以降低 TTFT。概念基线见 [vLLM Context Parallel 文档](https://docs.vllm.ai/en/latest/serving/context_parallel_deployment/)。K3 专项 [DCP PR #50484](https://github.com/vllm-project/vllm/pull/50484) 与 [Shared-CP RFC #50127](https://github.com/vllm-project/vllm/issues/50127) 在截止日仍为开放工程项，K3 的 PCP 仍是跟踪项，不应表述为已稳定落地。注意，仓库现有训练资料 20a 中的 DCP 又是 `Dynamic Context Parallelism`，与推理侧 DCP 不是同一技术。

> **版本快照**：vLLM 从 W26 的 v0.23.0 依次推进到 v0.24.0（06-29）、v0.25.0（07-11）、v0.25.1（07-14）、v0.26.0（07-27）；SGLang 从 v0.5.13 推进到 [v0.5.17](https://github.com/sgl-project/sglang/releases/tag/v0.5.17)（08-08），新增 Kimi K3、KDA-aware prefix caching、HiCache L2、AMD MI35x 验证及 Rust server PD。另可扫 [vLLM AFD Plugin](https://vllm.ai/blog/2026-07-23-vllm-afd-plugin)，但它与本节 MoE/connector 主线重叠，不再单列。
