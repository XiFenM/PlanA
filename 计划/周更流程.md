# 周更流程（Weekly Resource Update Workflow）

> **使用方式**：每周末（建议周日晚）打开一个**全新的 Claude Code 会话**，切到仓库根目录，把这句话发给 Claude：
>
> > 请严格按 `计划/周更流程.md` 的规范，为本周执行一次全板块资料周更。
>
> Claude 会自动完成搜索、过滤、写稿。你只需在最后做"晋级评审"（哪些条目值得从周报晋升到稳定版 `学习指引.md`）。

---

## 1. 项目上下文（给新会话的 Claude 看）

- **仓库用途**：一位 AI 框架开发工程师的面试准备仓库，目标岗位优先级 **推理框架 > 训练框架 > 算子开发**，5 个月内进入面试窗口。
- **学习架构**：8 个板块（见下），每个板块有稳定版 `学习指引.md`（学习计划），由 `计划/主计划.md` 统筹 20 周排程。
- **今日任务**：从 8 个板块各自的"长期订阅"源 + 行业关键词搜索中，捞出**过去 7 天**的新资料，写一份**本周周报**，不动稳定版指引。

**8 个板块与对应指引文件**：

| 板块 | 指引路径 |
| --- | --- |
| 推理框架（Track A 核心）| `推理框架/学习指引.md` |
| PyTorch Internals | `Pytorch/学习指引.md` |
| 训练框架 / 分布式 | `训练框架与分布式/学习指引.md` |
| 并行计算 / 算子 | `并行计算编程/学习指引.md` |
| 模型理论 | `模型理论/学习指引.md` |
| Leetcode | `Leetcode/学习指引.md` |
| 编译器（Track B）| `编译器/学习指引.md` |
| TPUs（Track B）| `TPUs/学习指引.md` |

---

## 2. 周更目标

产出**一份**周报文件：`计划/周报/YYYY-Wxx.md`（ISO 周编号，如 `2026-W17.md`）

周报只收**这 7 天内**新出现、且**不在稳定版指引和历史周报里**的高质量条目，每条必须回答：
- **这是什么**（1 句标题）
- **链接**
- **为什么值得看**（1 句，面试/学习价值）
- **建议归属板块**
- **建议学习节点**（精读/略读/扫一眼）

## 4. 执行步骤

### Step 1：定位周编号 + 建文件

```bash
date +"%G-W%V"     # 例：2026-W17
```

创建 `计划/周报/YYYY-Wxx.md`（模板见 §5）。

### Step 2：并行搜索（强烈建议用 Agent 并行）

派 **2–3 个** general-purpose agent 并行，每个 agent 负责 3–4 个板块：

- **Agent 1**：推理框架 + PyTorch Internals + 模型理论
- **Agent 2**：训练/分布式 + 算子 + 编译器
- **Agent 3**：TPUs + Leetcode（轻量）+ 跨板块综述/会议

**给每个 agent 的统一任务模板**（粘到 prompt 里）：

```
你负责以下板块的本周资料搜集：{板块列表}。

今天是 {YYYY-MM-DD}，目标窗口是过去 7 天（{YYYY-MM-DD - 7 天} 至今）。

对每个板块：
1. 用 WebFetch 依次访问 §3.1 里对应的订阅源，提取最近 7 天的新文章标题+链接+日期。
2. 用 WebSearch 搜索 §3.2 对应关键词（加 "site:arxiv.org" 和日期过滤），找 2025-2026 的新论文。
3. 对每条候选，按 §7 过滤标准判断是否入选。
4. 入选的条目按 §5 "单条目结构" 格式化返回。

返回格式：Markdown，分板块列表。每个板块不超过 5 条（宁缺毋滥）。
如果某板块本周无有价值更新，写"（本周无高价值更新）"。
不要重复已有内容（稍后主控 Claude 会做去重）。
```

### Step 3：去重

主控 Claude 收到 agent 结果后，对每条候选：

1. `grep -rn "<链接或关键词>" 推理框架/学习指引.md Pytorch/学习指引.md ...` 检查是否已在稳定版指引里。
2. `ls 计划/周报/*.md` 扫历史周报，检查是否上周已登记。
3. 若重复则剔除。若是更新版本（如 EAGLE-2 → EAGLE-3），保留但标注"替代 XXX"。

### Step 4：写周报文件

按 §5 模板填入 `计划/周报/YYYY-Wxx.md`。

### Step 5：晋级建议

在周报末尾写一节 **§晋级候选**，列出**本周最值得从周报晋升到稳定版 `学习指引.md`** 的 top 3–5 条（不一定每周都有），由用户最终决定。

**不自动修改 `学习指引.md`**——晋级是人工决定，避免污染稳定课程。

## 6. 搜索策略细节

### 6.1 博客扫描

- 对列表页（如 `https://blog.vllm.ai/`）用 WebFetch 抓标题+日期。
- 只看最近 7 天。对日期显示模糊的（仅"X days ago"），按可见顺序取前 5 条判断。
- 若 WebFetch 返回 403/404，换用 WebSearch + `site:<domain>` 做兜底。

### 6.2 ArXiv 搜索

- 用 WebSearch：`<关键词> site:arxiv.org 2026`（或对应年份）。
- 对候选论文用 WebFetch 打开 abstract 页，检查日期在窗口内。
- 只入选 **v1 提交日期** 在 7 天内的（避免老论文 v2 刷版也算新）。

### 6.3 GitHub Release 扫描

- 目标仓库 Release 页，取 `created_at` 在 7 天内的 release。
- 大版本号跳跃（v0.4 → v0.5）或带 "breaking" 标签的优先入选。

### 6.4 跨语言来源

英文为主；中文博客（如知乎专栏、微信公众号）在有独家工程实战时可入选，但**必须同时标注英文替代资料**（如果有）。

## 7. 入选过滤标准

**必须满足以下至少 1 条才入选**：

- ✅ 来自订阅列表中的一线源，且是新文章
- ✅ ArXiv 新论文且已在 MLSys/OSDI/SOSP/NSDI/NeurIPS 主会接收
- ✅ ArXiv 新论文且 GitHub 有配套实现（repo 在 100+ star 以上）
- ✅ 来自 vLLM / SGLang / PyTorch / Triton / Megatron / FlashInfer / Dynamo / Mooncake 等核心项目的重大 release
- ✅ 明确回应了稳定版 `学习指引.md` 里的 `TODO` / `待补` 或纠正了已收录资料的过时之处

**以下一律剔除**：

- ❌ 营销软文（产品发布、融资新闻、排行榜）
- ❌ 无代码、无数据、纯观点的 tweet 级内容
- ❌ 已经在稳定版指引或历史周报登记过的（即使标题略有差异）
- ❌ 距离 `学习指引.md` 当前重点窗口（本周主攻板块）超过 2 个板块的内容

**质量尺度**：宁缺毋滥。一周 0–3 条优质内容比 20 条注水好。

## 8. 晋级机制（周报 → 稳定版指引）

每月底的周报（如 `2026-W17.md`）生成后，用户**人工扫**本月 4 份周报的"§晋级候选"列表，决定哪些升入稳定版：

1. 选中条目 → 打开对应 `学习指引.md`。
2. 在对应 §资料清单 中插入新条目，按现有格式（🟥/🟨/🟩 + 精读/略读/跳过 + 时间预算）。
3. 如果该条目替代了老条目（如 EAGLE-3 替代 EAGLE-2），**保留老条目的 ID 位置**，在行内加"（替代自 <老条目>，<日期>）"注解。
4. 在稳定版指引顶部维护一个 `Changelog` 节，记录晋级事件：
   ```
   ## Changelog
   - 2026-05-03 (W18)：新增 FlashInfer 论文到 §B，替代原 §B-4 的 vLLM V1 kernel 粗略描述
   ```

晋级后**不要**从周报里删除老条目——周报是历史快照。

## 9. 运行示例

**用户操作**（周日晚上）：

1. 新开会话，`cd /root/workspace/PlanA`
2. 发消息：
   > 请严格按 `计划/周更流程.md` 的规范，为本周执行一次全板块资料周更。
3. 等 10–20 分钟（多个 agent 并行搜索）
4. 读生成的 `计划/周报/YYYY-Wxx.md`
5. 每月底扫一下 §晋级候选，决定是否升入稳定版

**Claude 操作**（按本文件流程）：

1. `date +"%G-W%V"` 拿周编号
2. `ls 计划/周报/` 看上周周报（为了对齐风格 + 作去重参考）
3. 派 3 个 Agent 并行跑搜索
4. 主控 Claude 汇总 + 去重 + 按 §5 模板写周报
5. 最后列晋级候选（3–5 条）
6. 输出周报路径给用户

---

## 10. 元规则

- **不修改稳定版**：本流程**绝不**自动写入任何 `学习指引.md`。只写周报。
- **不写给自己看**：周报写给**1 个月后回来扫的你自己**看，所以"价值"一句话必须能让半个月后的你立刻判断要不要读。
- **绝不堆数量**：本周没好货就诚实写"本周无高价值更新"，不用凑数。
- **语言一致**：周报全中文，但英文专有名词（如 FlashInfer、PagedAttention）保留原文。
