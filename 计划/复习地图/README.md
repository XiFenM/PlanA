# 复习地图与跨周回捞总表

> 本目录是 PlanA 的**纯复习辅助层**，承载“一页回忆地图 + 跨周回捞总表”，**不是学习状态、验收证据或工时账本**（当前课程与进度仍只看[唯一学习断点](../学习断点.md)和[八周冲刺进度](../八周冲刺进度/)）。
> 具体操作规则由中央 `guide-learning`（[review-loop.md](../../.agent-skills/skills/guide-learning/references/review-loop.md)）、`memo-cards` 与 `vivid-language` 拥有，本页只保存 PlanA 的路径映射与唯一回捞表。

## 1. 四层复习闭环（PlanA 落脚点）

| 层级 | PlanA 位置 / 触发 | 做什么与怎么用 |
| --- | --- | --- |
| **1. 一页回忆地图** | 本目录按周一个 `.md`（如 [W3-PD与KV.md](W3-PD与KV.md)） | 结课按需浓缩成 ≤20 行大白话骨架（主矛盾 + 4–6 步因果链 + 3 条辨析 + 真实坑），正文放 `<details>` 折叠块；复习前看自测口令盲顺 2 分钟再展开对照。 |
| **2. 追剧卡 + 人话卡（墨墨）** | `{板块}/cards/`（如 [推理框架/cards/](../../推理框架/cards/)） | 流程/生命周期/排障类优先用 4–6 集**美剧单集式故事卡**（短头标 + 1 句前情提要支持乱序弹出），辨析与踩坑用极简人话卡；每单元软目标 4–8 张，单卡约 80–180 字，卡面零 commit hash、去防御免责腔；回忆地图可直接兼作章节第 0 张总览卡。 |
| **3. 随时 5 分钟费曼微口述** | 随时发“来 5 分钟微口述”（可指定单元或让我按总表抽） | **不绑在开新课前**，方便说话或打字时单点触发（推荐直接语音转文字）。固定 3 个来回、5–8 分钟必收工：面试场景盲讲 60–90 秒 → 1 屏体检加 1–2 个追问 → 接招并 30 秒重讲卡壳段。默认零写入，练完只更新下方回捞表；讲顺的比喻可反哺地图。 |
| **4. 跨周交错回捞** | 下方唯一跨周回捞总表 | 抽题优先级：`⬜ 未练` → `🟡 卡壳`（3–5 天后再抽）→ `🟢 顺口`（14–21 天后再抽）。周末可选 2 个跨周主题做 25 分钟串讲，把前后机制连成一张网。 |
