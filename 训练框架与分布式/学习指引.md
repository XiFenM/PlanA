# 训练框架与分布式学习指引（4 周主线 / Track A 核心）

## 0. 入场点

- **为什么学**：这是你的第二优先方向（Megatron-Core / FSDP / NeMo / 自研训练栈 岗位）。你最关心的是"**给定不同规模硬件（8 卡 / 千卡 / 万卡）和不同规模模型（7B / 70B / 405B / 671B MoE），怎么设计最优的并行策略**"——这也是训练系统岗面试的核心决策能力。这份指引的主干就是围绕这个问题建立起来的。
- **终点（4 周后必须能做到）**：
    1. **策略设计白板题**：给任意 (模型规模, 硬件规模, 互联带宽, 预算) 组合，能在 15 分钟内给出 DP/TP/PP/CP/EP 维度的推荐配置，并用带宽-算力-显存三张账推导合理性
    2. 白板讲 FSDP2 的 per-parameter DTensor sharding、AllGather / ReduceScatter 通信时序、和 ZeRO-3 / FSDP1 的差异
    3. 白板讲 Megatron TP 在 MLP（列切→行切）和 Attention（head 切）两处的 AllReduce 放置，讲清 Sequence Parallel 能省多少 activation
    4. 白板讲 1F1B vs Interleaved 1F1B vs Zero-Bubble 气泡公式，以及 DeepSeek-V3 DualPipe 怎么做到双向重叠
    5. 画出 Llama-3 16K GPU 训练的 4D 并行（TP+CP+PP+DP）拓扑 + DeepSeek-V3 2048 H800 训练的 EP+PP+DP 拓扑，并解释为什么这么配
    6. 能读 torchtitan 源码并解释它怎么用 DTensor 串起 FSDP2 + TP + PP + CP
    7. 回答 [common_problems.md](../面试准备/面试问题经验/common_problems.md) 里："tp 并行 Megatron 实现"、"cuda 多线程中线程安全的生产者消费者队列"（通信库视角）
- **你已经会 vs 你不会**（校准）：你日常**会用** `torch.distributed` 做多卡通信，工作中还**把多流改成单流提速 10 倍**（说明你对通信语义有直觉）。你**不熟**：FSDP2 的 DTensor 抽象、Megatron TP 在 attention head 维切分的数学、PP 各种 schedule 的气泡公式、MoE 的 expert parallel 通信、千卡以上规模下的故障恢复。这份指引把时间往"策略设计 + 实际千/万卡案例（Llama-3、DeepSeek-V3、MegaScale）"倾斜。
- **时间预算**：4 周 × 32.5h − (Leetcode 4h/周 + 杂项 ~2h/周) ≈ **106h**
