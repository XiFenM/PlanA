## 3. H2D 与 D2H 是两个项目

- **H2D** 是历史正确性问题修复：Host 准备尚未完成时，下游可能提前消费设备数据；结果以有界请求集回归为主。
- **D2H** 是后端新能力实现和性能实验：满足异步提交条件并保护设备／Host 生命周期；结果包括代码、契约验证和不同负载下的正负性能对照。
- 二者可以共同支撑“异步执行与缓冲区生命周期”能力，但不能混用时间、修改范围、测试数据或收益，也不能与 W3 的 PD/RDMA 学习设计合并成同一生产项目。
