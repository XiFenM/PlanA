最近我在既有 vLLM 插件中负责 GLM-5.3-Flash 的模型接入、缓存管理、性能优化和发布验证。一个具体问题是，两类模型状态放在同一页后形成非连续视图，在目标后端上触发了开销较大的 Host 逐元素搬运。我通过 Profile 和隔离微基准定位这条路径，将两类状态拆成独立连续池，并同步处理清零、绑定与状态迁移，保持原有块编号语义，通过单测和真机对照验证。

这个项目中，框架和插件侧的修改由我负责；融合 Kernel 由算子团队实现，我负责调用契约、验收和接入。文本推理版本已完成交付，由云服务团队上线。

另一个案例是异步 H2D 的低概率输出异常。我定位到原等待没有覆盖 CPU 数据准备和拷贝提交，随后在框架和后端层补齐了异步标记与等待。这个修复复用了已有 Runtime 能力，恢复原异步配置并撤去临时阻塞后，现场请求回归未再复现原异常。

我希望继续负责框架执行与后端接口相关模块，在设计、实现、回归和版本维护中承担明确责任。
