## 代表项目

### ECG 客户模型部署与时延优化

面向客户基于 Transformers 的 ECG 多模态模型，负责环境搭建、适配验证、性能分析与服务交付，围绕客户的端到端时延目标推进优化。

- 通过 Profile 分析 Host 准备、小 shape 计算和矩阵乘开销，调整执行路径并接入融合算子；结合 Roofline 初步估算选择权重访存优化方向。
- 在 PyTorch 框架侧实现静态权重预排布，供 prefill／decode 复用，与算子团队协同集成。同芯片新旧布局对照中，MatMul 和模型 logits 逐元素数值相等，输出 Token 一致。
- 联合优化后，单请求端到端时延从 **30–40 s 降至 20 s 以内**，达到客户验收目标。优化前后各测 **10 次取平均**，包含图像预处理与完整输出，平均生成约 700–800 token；结果包含 Host、小 shape、融合与布局改动的共同收益。

### 多模态模型的 Conv3D 布局适配

- 从 Qwen 视觉模型的视频输入 OOM 提取真实 shape 单例，定位通道末置处理引发的小通道重复补齐；负责模型调用重构与初始化权重布局，与算子团队共同确定接口方案。
- 保留二维展平输入和权重，衔接算子团队实现的专用 Conv3D，联合方案消除了已观察到的 OOM。在 **Qwen2.5-VL-32B 的 10 个图片测例**中，单请求平均 TTFT 从分钟级降至 **5 秒以内**，输出 Token 与 CPU Conv3D 路径一致。

### 客户现场异步 H2D 精度异常修复

- 基于现场同事收集的异常请求，建立确定性重放与异步／阻塞对照，从首个分叉 Token 和中间 Tensor 缩小范围；先提供阻塞 H2D 的临时规避方案，再定位 CPU 准备与拷贝提交之间的依赖缺口。
