## 一、算子与 Kernel 优化

### 算子优化有哪些常用手段？

#### 已有记录

- 算子融合：可以重构算法逻辑。
- Ping-Pong：让传输与计算并行，使用 Double Buffer 交换 VMEM 块。
- 软件流水线：
  - 分为序言和稳态两个阶段。
  - 序言阶段连续发送多个 MatMul 指令。
  - 稳态阶段一边获取 MatMul 结果，一边发送后续 MatMul 指令。
- 使用 Mask 控制数据流。
- 使用模板化 Kernel 预处理分支，将分支判断提到 CPU 侧，借助 CPU 的控制能力和分支预测。
- 跨越 `for` 循环进行指令展开与重排。
