### C008 现有测试与最小实机验证

- **检查位置**：状态池、绑定、清零、缓存分组、gather／scatter 与 Graph 的已有测试及对应结果。档案中的测试数量用于寻找记录，具体参数与断言决定覆盖范围。
- **怎么查**：优先把已有用例按下表归类。仍影响复用判断、但缺少证据的条件，再使用目标环境已有的最小入口检查；记录命令、版本、输入和实际结果。参数变式用于验证接口条件，不等同于另一完整模型已交付。

| 条件 | 最少要核对的行为 |
| --- | --- |
| 已发布的 GLM 状态规格 | 分配、绑定、初始化及状态读写与既有结果一致。 |
| 接口声称支持的不同规格 | 改变 block 数或合法的状态维度后，形状与字节核算正确，写入指定 block 后可读回，其他 block 不被改写。 |
| 不满足拆池条件的规格 | 进入已声明的回退或明确报出不支持；绑定和容量核算与实际选择一致。 |
| 请求结束后复用状态块 | 按实现约定初始化，新请求不会读到上一请求残留的有效状态。 |
| 已支持的 Graph padding 场景 | 补齐槽不会污染有效状态；同配置的 Graph／eager 对照满足已有判据。 |

- **带回证据**：每项已有／新查用例的输入、断言、结果和证据定位。仅运行了 GLM 固定配置时如实记录；若要报告性能，另附相同负载、布局、计时范围和同步方式的对照。
- **影响答法**：把“接口设计上可适配”“不同规格已验证”和“其他完整模型已验证”分开表达。
